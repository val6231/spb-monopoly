# Монополия. Санкт-Петербург (MVP)

Классическая Monopoly в браузере с тематикой Санкт-Петербурга. Онлайн, 4–8 игроков,
комната по короткому коду. Сервер авторитетный: вся игровая логика на сервере,
клиент отправляет только намерения.

**Стек:** Node.js + Express + Socket.IO · React + Vite · состояние комнат в памяти.

Архитектура, модель данных и список socket-событий — в [ARCHITECTURE.md](./ARCHITECTURE.md).

## Структура

```
server/            авторитетный сервер
  core/            ядро правил без сети (state, rules, property, cards, rng)
  index.js         Express + Socket.IO, прод-статика client/dist
  rooms.js         комнаты в памяти, коды, токены переподключения
  gameSocket.js    обработка намерений клиента, рассылка state:update
  test/            юнит-тесты ядра + интеграционный тест синхронизации
client/            React + Vite (лобби, поле 11x11, панели, модалки)
shared/board.json  поле 40 клеток (группы — районы СПб, вокзалы, коммуналки)
shared/cards.json  колоды «Разведённые мосты» и «Городской фонд» (по 16 карт)
```

## Запуск

Требуется Node.js ≥ 18.

### Установка зависимостей

```bash
npm install
```

(monorepo на npm workspaces: подтянутся зависимости и для `server/`, и для `client/`)

### Тесты

```bash
npm test
```

Прогоняет юнит-тесты ядра правил и интеграционный тест онлайн-синхронизации
(node:test, без внешних сервисов).

### Разработка

```bash
npm run dev
```

Одновременно поднимаются:

- сервер — `http://localhost:3001` (`node --watch`);
- клиент (Vite dev-сервер) — `http://localhost:5173`, проксирует `/socket.io`
  и `/shared` на порт 3001 (см. `client/vite.config.js`).

Откройте `http://localhost:5173` в нескольких вкладках или на нескольких
устройствах в вашей сети (во втором случае — по адресу хоста, например
`http://192.168.x.x:5173`).

### Прод-сборка

```bash
npm run build   # vite build -> client/dist
npm start       # NODE_ENV=production node server/index.js
```

После этого всё приложение (API, сокеты, статика клиента) отдаётся с одного порта:
`http://localhost:3001`. Сменить порт: `PORT=8080 npm start`.

## Как играть

1. Первый игрок создаёт комнату в лобби, получает короткий код; остальные входят
   по коду, выбирая фишку и цвет (4–8 игроков). Хост запускает партию.
2. По своему ходу: бросок двух кубиков → перемещение → действие клетки.
   - Дубль — дополнительный ход; три дубля подряд — сразу на «Кресты».
   - Свободную собственность можно купить у банка; отказ — остаётся у банка
     (аукциона в MVP нет).
   - Рента владельцу; при полной группе без построек — ×2.
   - На своей группе стройте «этажи» до 4 и «бизнес-центр», равномерно (±1).
   - Проход старта — зарплата 200.
3. Тюрьма «Кресты»: выход дублем, оплатой 50 или картой «Освобождение»;
   максимум 3 хода, затем штраф и обязательный выход.
4. Не смогли заплатить — ликвидация активов (залог/продажа); банкротство
   выбивает из игры. Побеждает последний платёжеспособный игрок.

Переподключение: токен игрока хранится в `localStorage`; при разрыве связи или
обновлении страницы клиент автоматически возвращается в свою комнату и слот.

## Как позвать друзей

**Вариант 1 — одна Wi-Fi сеть (проще всего).**
Сервер и Vite слушают все интерфейсы (`HOST=0.0.0.0`, `host: true`), поэтому
друзья заходят по IP вашей машины:

```bash
npm run build && HOST=0.0.0.0 npm start   # прод-режим, всё на одном порту 3001
# узнайте свой IP в локальной сети, например: hostname -I  (Windows: ipconfig)
```

Отправьте друзьям ссылку вида `http://192.168.1.42:3001`. Они открывают лобби,
вводят код вашей комнаты — и играют со своих устройств. Для dev-режима
(`npm run dev`) вместо этого — адрес `http://<ваш-IP>:5173`.

**Вариант 2 — через интернет (друзья не в вашей сети).**
Раздайте туннель до локального порта без деплоя, например:

```bash
npx localtunnel --port 3001        # даст публичный URL https://<имя>.loca.lt
# либо: ssh -R 80:localhost:3001 serveo.net, либо cloudflared tunnel --url http://localhost:3001
```

Или залейте проект на любой Node-хостинг (Render/Fly/Railway): команда запуска
`npm run build && npm start`, переменная `PORT` подставляется автоматически.

Нюансы: состояние комнат в памяти одного процесса — все должны заходить на один и тот
же сервер; при рестарте партии сбрасываются. Если друзья не видят страницу —
проверьте, что firewall разрешает входящие подключения на порт 3001 (5173).

## Полезно знать

- Состояние комнат — в памяти процесса: рестарт сервера сбрасывает все партии.
- Контент поля и карт правится в `shared/*.json` без изменения кода.
